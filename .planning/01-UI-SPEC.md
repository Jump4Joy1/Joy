## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, micro spacing |
| sm | 8px | Compact element spacing |
| md | 16px | Default element padding |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Link vertical gap: 14px (from reference, non-standard override)
- Icon-only touch targets: 44px minimum
- Button min-height: 64px (from reference)

## Component Inventory

### Avatar
- Circular image, 96px mobile / 120px desktop
- Border: 3px solid #bb8773
- Shadow: 0 4px 20px rgba(34,102,145,0.4) (using accent color)
- Fallback: initials on #bb8773 background

### Profile Header (avatar + username + bio)
- Vertical stack: avatar (top), username, bio
- Spacing: 24px gap between avatar and username, 12px between username and bio
- Centered, max-width container

### Social Links Row
- Instagram icon + TikTok icon in horizontal row
- Icon size: 32px
- Gap: 24px between icons
- Positioned above content links with 32px top margin
- Icons use #bb8773 color, hover: #226691 accent glow

### Content Link Button
- Full-width within content container
- Min-height: 64px
- Padding: 14px horizontal, 16px vertical
- Border: 1px solid #bb8773 (outline style)
- Border-radius: 8px
- Background: #bb8773
- Text: #050f15, Space Grotesk 500 16px
- Gap between links: 14px
- Hover: translateY(-2px), box-shadow 0 8px 24px rgba(34,102,145,0.3)
- Transition: cubic-bezier(0.08, 0.59, 0.29, 0.99)

### OnlyFans Sensitive Content Gate
- Initial state: link button shows "OnlyFans" with lock/shield icon overlay
- On click: modal overlay appears over the button area
- Overlay: dark semi-transparent backdrop (#050f15 at 90% opacity)
- Gate card: centered, max-width 320px, background #0a1a24, border 1px #bb8773
- Heading: "Sensitive Content" — Space Grotesk 700 20px #ffffff
- Body: "This link contains sensitive material. By continuing you confirm you are 18+ years of age." — Inter 400 14px #c58c77
- CTA button: "I am 18+, Enter" — full-width, background #bb8773, text #050f15
- On CTA click: gate dismissed, OnlyFans link becomes clickable and opens in new tab

### Page Layout
- Single column, vertical stack
- Max-width: 580px desktop, 100% mobile (with 16px horizontal padding)
- Page background: #050f15
- Content centered horizontally
- Page-level top padding: 64px mobile, 80px desktop
- Page-level bottom padding: 64px
